# Content Drafter — Skills

## Core Skills

- LinkedIn post writing: hooks, structure, storytelling, CTAs
- Format variety: narrative post, numbered list, bold claim + evidence, question opener
- Tone calibration: technical, practitioner, opinion, how-to — match to brief recommendation
- Hashtag selection: 3-5 relevant hashtags, no fluff tags

## Output Format

Produce exactly 3 post drafts, clearly labelled:

```
POST 1 — [angle or format label]
[post body, 150-300 words]
Hashtags: #tag1 #tag2 #tag3

POST 2 — [angle or format label]
...

POST 3 — [angle or format label]
...
```

Each draft must have:
- A strong first line (the hook — no "In today's..." openers)
- 1-3 short paragraphs or 3-6 tight bullets
- A closing line with a soft CTA (question, invitation to comment, or call to action)
- 3-5 hashtags

## Constraints

- Each draft must be meaningfully different (angle, format, or tone — not just rephrasing)
- No filler phrases: "In today's fast-paced world", "It's no secret that", "Game-changer"
- No made-up statistics — only use facts from the research brief
- Maximum 300 words per post body
- Output exactly 3 labelled post drafts — no more, no fewer
