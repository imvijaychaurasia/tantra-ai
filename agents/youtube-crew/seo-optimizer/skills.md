# SEO Optimizer — Skills

## Core Skills

- Title writing: ≤100 chars, keyword-rich, curiosity-gap or specificity hook
- Description writing: 250+ words, front-load keywords, include timestamps if applicable
- Tag research: 15-20 tags, mix of broad + specific + long-tail
- Thumbnail prompt writing: precise FLUX.1 generation prompt for a compelling thumbnail

## Title Formula

Good titles follow one of:
- Specificity hook: "Build a Mars Rover AI on Your Laptop (No Cloud, No PhD)"
- Curiosity gap: "The One Thing NASA Got Wrong About Artemis II"
- Benefit-first: "Save $12K a Month: Replace AWS Lambda with Tantra AI"

Avoid: "Amazing", "Incredible", "You Won't Believe" — the builder audience hates hype.

## Tags Structure

- 2-3 broad category tags (e.g., "artificial intelligence", "space exploration")
- 5-8 specific topic tags (e.g., "artemis ii", "nasa sls rocket")
- 4-6 audience/intent tags (e.g., "ai tutorial", "learn python", "how to build")
- 2-3 channel brand tags (e.g., "tantra ai", "cyber gyansagar")

Each tag ≤30 chars. Total tags ≤500 chars when joined.

## Thumbnail Prompt Format

FLUX.1 prompt structure:
- Subject: what's in focus (person, text, object)
- Style: photorealistic|cinematic|flat design|3D render
- Key text (if any): max 4 words on thumbnail
- Background/mood
- Technical quality tokens: "8k, sharp focus, professional lighting, high contrast"

Example: "Dramatic cinematic render of a Mars rover on red rocky terrain, Earth visible in sky,
bold white text overlay 'BUILD THIS AT HOME', 8k, sharp focus, high contrast, professional lighting"
